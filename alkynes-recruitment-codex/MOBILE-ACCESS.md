# 휴대폰 개인 접속

1. 노트북 앱을 업데이트하고 **설정 → 휴대폰 개인 접속**을 엽니다.
2. 노트북과 휴대폰의 Tailscale을 같은 계정으로 연결합니다.
3. 설정에 표시된 노트북 Tailscale IPv4를 선택하고, 12자 이상의 별도 접속 비밀번호를 정합니다.
4. **휴대폰 접속 켜기**를 누릅니다. 연결되면 표시되는 주소를 휴대폰 브라우저에 입력하고 비밀번호로 로그인합니다.
5. 휴대폰은 읽기 전용입니다. 설정·백업·엑셀 파일·앱 업데이트 API는 공개되지 않습니다. 접속 종료 버튼으로 로그아웃할 수 있으며 세션은 8시간 후 만료됩니다.

노트북 전원·Tailscale·앱 서버가 켜져 있어야 합니다. 절전이나 종료 중에는 접속할 수 없습니다. VPN이 앱보다 늦게 시작되면 30초마다 연결을 다시 시도합니다. 엑셀 반영은 **노트북 서버가 실행되는 동안 브라우저와 무관하게** 약 5초 간격으로 변경을 확인합니다. 휴대폰 화면은 노트북 DB의 갱신 내용을 약 3초 간격으로 확인합니다.

앱 기본 포트는 로컬 전용 8790, 휴대폰 조회는 별도 8791입니다. 조회 서버는 선택한 Tailscale IPv4에만 바인딩하며, 전체 네트워크(0.0.0.0)에 열지 않습니다. 공유기 포트 개방이나 Tailscale Funnel은 필요하지 않습니다. Windows 방화벽에서 차단되면 회사 정책에 따라 Tailscale 어댑터의 조회 포트만 허용해야 합니다. 로컬 8790을 외부에 열지 마세요.

HTTP 주소는 Tailscale의 암호화된 VPN 내부에서만 사용합니다. 비밀번호는 로컬 설정 폴더에 무작위 salt와 scrypt 해시로 저장됩니다. 원문·주소·DB 파일을 GitHub에 올리지 마세요. 접속 설정 저장, 접속 끄기 또는 서버 재시작 시 기존 로그인은 폐기됩니다. 인증 전에는 데이터가 제공되지 않으며 로그인 실패는 기기 주소별로 10분간 5회로 제한됩니다.

Tailscale의 **회사 업무용 무료 이용 자격은 확인되지 않았습니다.** 실제 사용 전에 현재 요금제·약관과 회사 정책을 확인하세요. 앱은 요금제를 신청하거나 공용 사이트를 만들지 않습니다. 다른 VPN이 휴대폰 VPN 연결을 점유하면 Tailscale 접속이 되지 않을 수 있습니다.

개발 검증은 합성 데이터·모의 VPN 클라이언트로 수행했습니다. 실제 사용자 Windows 노트북, Tailscale 계정 정책, 회사 방화벽, 외부 휴대폰 연결은 해당 기기에서 확인해야 합니다.
